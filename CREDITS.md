All code in this repository is an original implementation released under the MIT license (see LICENSE): the
`b2r` tools and library, the Blender scripts, the templates and the tests. The models and tools below are
called or imported, not redistributed; each keeps its own licence and terms. Where a licence is not stated
here, read the model card or project page before relying on it.

## Models

| Model | Source | Used for | Licence / terms |
|---|---|---|---|
| Nano Banana 2 (Gemini image editing) | Google; `fal-ai/nano-banana-2/edit` on fal | the photoreal target of the fixed view (grey render in, photo out) | closed model; Google's and fal's terms of use |
| Marigold V2 | PRS-ETH (ETH Zürich, Photogrammetry and Remote Sensing); `fal-ai/marigold-v2` on fal | albedo and camera-space normals of the target | see the model card |

| LPIPS | R. Zhang, P. Isola, A. Efros, E. Shechtman, O. Wang, "The Unreasonable Effectiveness of Deep Features as a Perceptual Metric", CVPR 2018; `lpips` package (AlexNet and VGG variants) | every re-render score, the per-object error map, the light-variant and detail selection | BSD-2-Clause |

The method ("imagine, then back-project": generate a photo of the grey render, then write that look back into
the scene as materials, lights and geometry) and the first run it was built on are described in the README.
Images in `gallery/` come from that run; the photoreal targets in them were generated by Nano Banana 2.
