# Gemini (Gem)

1. Create a Gem and paste `adapters/universal-system-prompt.md` (the part below the line) into its instructions.
2. Add `skills/blockout-to-real/SKILL.md`, `references/target.md` and `references/loop.md` as files.

For Gemini CLI, install the extension instead: `gemini extensions install https://github.com/gokayfem/blockout-to-real`.
